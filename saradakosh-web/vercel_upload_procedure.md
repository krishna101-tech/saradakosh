# Vercel Upload Procedure

Every time you push changes online, follow this exact procedure:

1. **Start Upload:** Commit your changes and push them to the remote repository.
2. **Monitor Vercel Site:** Check the deployment status on Vercel at [https://vercel.com/sri-ma/saradakosh](https://vercel.com/sri-ma/saradakosh). 
3. **On Error Fix Issue:** If the build fails, read the build logs, fix the code locally, and restart the upload procedure.
4. **Reupload/Resume Upload:** Commit and push the fixes.
5. **Loop Till Perfection:** Continue monitoring and fixing until you verify that the changes are successfully published and live on Vercel.

**Vercel Dashboard Link:** [https://vercel.com/sri-ma/saradakosh](https://vercel.com/sri-ma/saradakosh)
